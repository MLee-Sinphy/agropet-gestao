# Requisitos - AgroPet Gestão

## Objetivo

Desenvolver um sistema simples, rápido e intuitivo para registrar vendas, controlar estoque e gerar inteligência de negócios para petshops.

---

# Requisitos Funcionais

## Home

- Tela dividida em três áreas.
- Nova Venda.
- Entrada de Estoque.
- Inteligência.

## Nova Venda

- Cadastro implícito de clientes.
- Cadastro implícito de pets.
- Cadastro implícito de produtos.
- Autocomplete em todos os campos.
- Salvar venda em poucos cliques.
- Histórico de compras.

## Entrada de Estoque

- Registrar entrada de produtos.
- Atualizar estoque.
- Registrar validade.
- Registrar fornecedor.
- Compatível com o Bling.
- Campos avançados ocultos por padrão.

## Inteligência

- Dashboard.
- Gráficos.
- Alertas.
- Clientes inativos.
- Frequência de compras.
- Produtos mais vendidos.
- Produtos menos vendidos.
- Estoque baixo.
- Produtos próximos da validade.
- Tendências de vendas.
