# Interface - AgroPet Gestão

## Filosofia

O sistema deve ser simples, rápido e intuitivo. O usuário deve registrar uma venda em poucos segundos, com o mínimo possível de cliques e digitação.

---

# Home

Tela dividida em três áreas.

## Área 1

Nova Venda

Objetivo:
Registrar rapidamente uma venda.

---

## Área 2

Entrada de Estoque

Objetivo:
Adicionar novos produtos ou repor estoque.

---

## Área 3

Inteligência

Objetivo:
Exibir métricas, gráficos, alertas e insights sobre clientes, produtos e vendas.

---

# Nova Venda

Fluxo:

Cliente
↓

Pet
↓

Produto
↓

Quantidade
↓

Salvar

Regras:

- Autocomplete para clientes.
- Autocomplete para pets.
- Autocomplete para produtos.
- Caso não exista, criar automaticamente.
- Sem tela de cadastro de clientes.

---

# Entrada de Estoque

Campos principais sempre visíveis.

Campos avançados ficam recolhidos em "Mais opções".

Compatível com o Bling.
